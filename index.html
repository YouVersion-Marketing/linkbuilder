How to Use the Link Builder

Turn any Bible reference into links you can share—in as many translations and languages as you need.

Build your links
  1. Enter a referenceType a book, chapter, and verse—like John 16:33. We check it as you type and show it as a tag below the field.
  2. Add more than oneSeparate references with a comma, semicolon, or a new line—like John 16:33, Matthew 1:1—to build links for several passages at once.
  3. Choose your translationsSelect the translation chips to add or remove them. Want more? Tap + More Translations, then Choose a Language to browse 394 versions in 32 languages.
  4. Copy or open a linkEvery result has Copy Link and Open. Tap Copy All Links to grab them all at once, one per line.
  5. Share it anywherePaste your links into a message, email, or post. Each one opens the verse right in the Bible App on web or mobile.
Good to know
  • A link covers a single chapter, so keep verse ranges inside one chapter—like Romans 8:28-39.
  • Tap the clear button by the reference tags to empty the field and start fresh.
